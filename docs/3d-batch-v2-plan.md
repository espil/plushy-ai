# 3D 배치 v2 계획 (2026-10-26)

## 폐기 범위 (Han 확정)

• PC 3D 배치 결과물 전부 (Waitematā 건물 18종 + 마을/동굴 43종의 GLB)와 그 입력 이미지 전부 (inputs/buildings_iso, inputs/villages_caves, 두 매니페스트)를 폐기한다.
• 유지하는 것: 아이소메트릭 제작물, 프론트뷰 원화 세트, Plushy AI 파이프라인 코드와 검증된 인프라는 그대로 둔다.

## 목표

• 질렌디아 인게임 사용이 1차 목표이고, 동시에 itch.io에서 판매 수익을 기대할 수 있는 에셋팩 품질을 합격선으로 한다. "팔릴 퀄리티인가"를 모든 판정 기준으로 삼는다.

## 무엇이 문제였나

• 마을/동굴 배치의 입력 이미지가 프론트뷰 일러스트 합성본이었다. 정면 한 장만으로 3D를 복원하면 볼륨과 뒷면이 뭉개진다.
• 변환 설정이 기본값 위주라 입력의 한계를 더 키웠다.

## 개정 1 - 입력 이미지 (프롬프트)

• 전 에셋의 원화를 아이소메트릭 3/4 뷰로 새로 제작한다. 지붕, 정면, 측면이 한 장에 읽혀서 복원할 볼륨 정보가 있어야 한다.
• 프롬프트 표준을 강화한다: 재질을 분리해 명시하고, 실루엣을 강조하고, 순백 배경에 중앙 배치하고, 복원을 방해하는 과밀한 장식은 뺀다.
• 마을 컨셉 v2 (이름과 위치에 걸맞은 디자인)를 원화에 반영한다.

## 개정 2 - 변환 설정

• 텍스처 해상도 상향을 샘플로 검증한다 (1024 대 2048, 파일 크기 규격과의 균형 포함).
• foreground ratio를 에셋별로 조정하고, remesh triangle 옵션을 샘플에서 비교한다.
• 배치 전에 샘플 1종으로 설정을 확정한다 (기존 규칙: 샘플 먼저, 확인 후 배치).

## 개정 3 - itch.io 판매 규격

• 폴더 구조와 파일명을 일관되게 통일한다.
• 접촉 시트 미리보기와 규격 문서 (삼각형 수, 텍스처 크기)를 팩에 포함한다.
• 스케일과 피벗을 전 에셋 통일한다.

## 진행 순서

• 대표 건물 1종으로 새 원화와 새 설정을 검증하는 샘플을 먼저 만든다.
• Han 확인 후 마을 순서대로 재제작한다.
